# Money Tracker

An application to manage & track monthly spendings.

## User Flow

1. User will be able to signup/login
2. The input for the users input their daily expenses or income would be via a chat interface
   Example
    :: "Got 15000 salary today"
    :: "Spent 30 Rs on Rickshaw to  work"
3. The data will get catagorized and stored into a database.
4. On the dashboard user will be able to view charts and analytics of their spendings and incomes.
